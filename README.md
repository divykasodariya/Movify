# 🎬 Movify

Discover, explore, and curate your perfect movie collection with Movify - your personal movie companion built with React. Save your favorites and discover new films with our sleek, modern interface.

## ✨ What is Movify?

Movify is your go-to platform for movie exploration. Whether you're searching for your next movie night pick or building your ultimate watchlist, Movify makes it simple and enjoyable.

## 🎯 Core Features

- **Smart Movie Discovery**: Browse through popular movies or search for specific titles
- **Personal Favorites**: Build and manage your personal movie collection
- **Real-Time Search**: Instantly find movies as you type
- **Rich Movie Details**: Get comprehensive information about each film
- **Smooth Experience**: Clean, responsive interface across all devices

## 🛠️ Tech Stack

- **React**: For building a dynamic user interface
- **Context API**: Efficient state management
- **Modern JavaScript**: ES6+ features
- **Custom Hooks**: Reusable logic
- **RESTful APIs**: External movie data integration

## 🏗️ Application Structure

Movify is built with modularity and scalability in mind:

### State Management
- `MoviesContext`: Handles global movie state
- `FavMoviesContext`: Manages favorites collection

### Key Components
- `Home`: Main movie discovery interface
- `Fav`: Your favorites collection
- `MovieCard`: Dynamic movie display component




## 💡 How to Use Movify

### Discover Movies
- Browse the homepage for popular movies
- Use the search bar for specific movies
- Click on movies for more details

### Manage Your Collection
- Click the favorite button to add movies
- Visit your favorites page to see your collection
- Remove movies from favorites easily

## 🔄 Behind the Scenes

Movify uses a dual-context architecture:
- `MoviesContext`: Main movie list management
- `FavMoviesContext`: Favorites system

Benefits:
- Efficient state updates
- Clean code structure
- Improved performance
- Easy maintenance
